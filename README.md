# Descubre Olimpo · prototipo interactivo

Este repositorio contiene el prototipo navegable de **Descubre Olimpo** para web y móvil. Permite recorrer la bienvenida, el primer depósito, las guías de Bonos e identidad y la experiencia de Club Olimpo. Las acciones son una simulación; no afectan una cuenta real.

## Ver el prototipo

**[Abrir Descubre Olimpo en GitHub Pages](https://stray-packet.github.io/olimpo-interactive-walktrough/)**

Es una sola experiencia adaptable: ábrela en una pantalla de escritorio para ver la versión web o en un teléfono para ver la versión móvil.

## Obtener los archivos

En GitHub, selecciona **Code → Download ZIP** o clona el repositorio:

```bash
git clone https://github.com/stray-packet/olimpo-interactive-walktrough.git
```

El prototipo y sus recursos están en [`prototype/`](prototype/). La documentación visual, los estados y las notas de comportamiento para implementación se entregan en [Figma](https://www.figma.com/design/P7cbXLU7bMuDiZNGEn2Xhp/-COMERCIAL--Onboarding-%7C-Interactive-Walktrough?node-id=4001-220).

> Este es un prototipo de referencia para la implementación. Los textos, imágenes y animaciones muestran la experiencia prevista; los pagos, la verificación de identidad y los bonos no se ejecutan realmente.

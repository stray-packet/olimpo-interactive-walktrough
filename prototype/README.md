# Prototipo de Inicio

Réplica visual editable de `https://www.olimpo.bet` limitada a Inicio. No contiene rutas reales, autenticación, lógica de apuestas ni enlaces externos navegables.

## Abrir

Abrir `index.html` en un navegador. Para desarrollo, servir esta carpeta como contenido estático.

## Interacciones incluidas

- Carrusel de banners automático con controles manuales.
- Menú lateral de perfil desde el avatar superior derecho; cierre con botón, clic fuera o tecla Escape.
- Estados de menú del perfil y estados hover de controles principales.
- Adaptación responsive para escritorio y móvil.

## Nota de diseño

Los banners usan recursos remotos observados en la página de Inicio. Sustituirlos por assets propios si el prototipo se distribuye fuera del entorno de diseño.

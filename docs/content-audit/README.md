# Auditoría de contenido — Olimpo

## Propósito

Centralizar el contenido existente que puede alimentar guías visuales de `Descubre Olimpo`. Esta auditoría no sustituye la revisión de Producto, Negocio, Legal o Compliance.

## Método y calidad de evidencia

Cada hallazgo conserva, cuando aplica:

- fuente y URL;
- texto o resumen fiel;
- fecha de consulta;
- nivel de certeza;
- uso potencial dentro de la guía;
- vacíos o validaciones pendientes.

### Estados

- **Verificado:** texto visible en una fuente de Olimpo.
- **Pista:** señal observada que requiere contrastarse contra condiciones o reglamento.
- **Pendiente:** información necesaria todavía no localizada o validada.
